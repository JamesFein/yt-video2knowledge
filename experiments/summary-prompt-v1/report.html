结论先行

这不是一次生产改造，而是一次隔离的提示词研究。最重要的成果是排除了不必要的分类路由，也暴露了同模型评审的循环偏差。

04

三轮提示词演化

真正有效的修改不是增加更多规则，而是找到最少、最关键的护栏。v2 是一个有价值的反例。

v1 · 最短懒提示

强调一个核心认识、最强论据、关键案例和自然正文。相对当前基线偏好率达到 87.5%。

失败：S055 把 ASR 中含混的学校和来源改成模型熟悉的真实名称，触发忠实性硬伤。

质量高 · 忠实性未过

v2 · 规则叠加

把四类自适应策略、专名保护、长度、标题和引语规则集中塞入一个提示词。

失败：仅 58.3% 胜过当前基线，只有 4.2% 胜过 v1，平均比 v1 低 0.650/5。

约束多 · 内容质量坍塌

v3 · 回归最小护栏

回到 v1，只增加 transcript 唯一事实来源、长度目标和引语边界。

结果：95.8% 胜过当前、7/8 稳定；但只有 41.7% 胜过 v1，且严格格式仍失败。

为什么最终不做分类路由

最终架构：分类只做研究标签

当前风险清单

忠实性假阳性

同模型评审可能把共同的常识纠错当作“与 transcript 一致”。必须由人工或不同验证机制复核。

长度失控

v3 平均 1,346 字符，范围为 702–1,712；8/24 篇超过硬上限。

引语不可核验

模型经常给转述加引号，或者没有附时间戳；严格逐字规则无法仅靠当前懒提示稳定执行。

人工偏好未知

模型偏好率很高，但真正使用文章的人尚未完成盲审，因此最终质量裁决仍空缺。

两条诚实的后续路径

路径 A · 保持硬门槛

另立长度与引语专项实验

先完成人工复核，再研究短文长度服从和逐字引语验证；如果允许提示词之外的确定性后处理，需要单独讨论并验证，不能在本轮暗中加入。

路径 B · 降级为写作偏好

人工复核后决定是否接受 v3

如果 1,500 字与引语时间戳不是硬门槛，可根据 12 组盲审决定是否将 v3 作为内容提示词候选；仍需解决独立忠实性验证。
