# Meta Summary Weak-Signal Analysis

Knowledge Site 中共有 22 条非空人工 Meta Summary。本实验把它们视为用户主动选择内容的弱信号，而不是标准答案，也不把它们放入随机评测集。

## 长度

- 最短：129 字符
- 中位数：657.5 字符
- 平均数：829.5 字符
- 最长：2,974 字符
- 18/22 不超过 1,200 字符

这支持把正常简写文章设为 600–1,500 字，而不是延续历史总结中大量多级标题和数千字罗列。

## 内容偏好

人工选摘反复保留以下内容：

- 能单独成立的核心判断或因果机制。
- 具体方法、判断框架和可执行步骤。
- 能解释抽象观点的案例或对比。
- 对主张适用边界的说明。

它们通常省略视频信息、铺垫、重复结论和泛化行动建议。因此新提示词应优先选择一个清楚认识及其最强支撑材料；行动建议只能由原文自然产生。

完整弱信号快照保存在 `data/experiments/summary-prompt-v1/meta-summary-signals.jsonl`。
